Privacy

This page describes what hederica.com does when someone opens a page. It is a description of the site’s own practice.

What is collected

Each visit is logged by email to the site owner. The note contains:

  • the time of the visit
  • the page, and the query string if there is one
  • the referring page, when the browser sends one
  • an approximate location taken from the IP address: country, region, and city, as the host supplies them
  • a masked IP address. For IPv4 the last octet is set to 0. For IPv6 only the first three groups are kept
  • the browser and device, read from the user-agent string
  • the language preference the browser sends

Why

The note is for understanding readership: which pages are opened, and from where, in a general way. It is not used to build an advertising profile.

Retention

The note is kept in the owner’s inbox until the owner deletes it. A first-party cookie, va_seen, remembers a browser for 24 hours so the same visitor does not generate another note that day. The cookie is not used for anything else.

No sale, no sharing, no ads

The site does not sell this information and does not share it with advertisers. It does not run ads or third-party trackers. The email goes to the site owner. Automated crawlers are not mailed.
